# 현장 청구/입금 체크 웹앱

현장별로 작업 내용, 비용, 청구 여부, 입금 여부, 입금일을 기록하고 체크하는 웹앱입니다.
Cloudflare Workers(서버) + D1(데이터베이스)을 사용하는 **진짜 서버 방식**이라, 어느 PC나
휴대폰에서 로그인해서 입력해도 같은 데이터를 보게 됩니다. (5초마다 자동 새로고침 + 화면
전환 시 즉시 새로고침)

- 비용: Cloudflare 무료 플랜으로 충분합니다 (Workers, D1 모두 무료 제공량이 넉넉함).
- 로그인: 회원가입 없이 **공통 비밀번호 1개**로 접속합니다. 비밀번호는 배포 시 직접 정합니다.
- 입금 완료된 내역은 표에서 배경색이 초록색으로 바뀌어 한눈에 구분됩니다.
- 현장 목록은 화면의 "현장 관리" 버튼에서 직접 추가/삭제할 수 있습니다. (코드 수정 불필요)

아래 순서대로 따라 하시면 됩니다. 한 번만 설정해두면 그다음부터는 계속 그 주소로
접속해서 쓰시면 됩니다.

---

## 0. 준비물

- Cloudflare 계정 (무료 가입, https://dash.cloudflare.com/sign-up)
- Node.js 설치 (https://nodejs.org 에서 LTS 버전 설치 — 설치만 하면 됨, 별도 설정 불필요)
- 이 zip 파일 압축 해제

## 1. 터미널 열고 폴더로 이동

압축을 푼 `hyunjang-payment-tracker` 폴더로 이동합니다.

- Windows: 폴더 안에서 주소창에 `cmd` 입력 후 Enter (탐색기 주소창을 클릭하고 cmd 입력)
- Mac: 폴더를 마우스 우클릭 → "새 터미널 창 열기" (또는 터미널 열고 `cd` 로 이동)

## 2. 필요한 패키지 설치

```bash
npm install
```

## 3. Cloudflare 로그인

```bash
npx wrangler login
```

브라우저가 자동으로 열리며 Cloudflare 로그인 화면이 나옵니다. 로그인 후 "Allow"를
눌러주면 터미널로 다시 돌아와서 완료됩니다.

## 4. 데이터베이스(D1) 만들기

```bash
npx wrangler d1 create hyunjang-payment-db
```

실행하면 아래처럼 결과가 나옵니다.

```
[[d1_databases]]
binding = "DB"
database_name = "hyunjang-payment-db"
database_id = "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
```

여기 나온 `database_id` 값을 복사해서, `wrangler.toml` 파일을 열고
`REPLACE_WITH_YOUR_D1_DATABASE_ID` 부분을 그 값으로 바꿔서 저장합니다.

## 5. 테이블 만들고 현장 목록 초기 등록

```bash
npx wrangler d1 execute hyunjang-payment-db --remote --file=./schema.sql
```

이 명령으로 표 구조와 처음 요청하신 22개 현장 목록이 데이터베이스에 들어갑니다.

## 6. 로그인 비밀번호 설정

```bash
npx wrangler secret put APP_PASSWORD
```

실행하면 비밀번호를 입력하라는 문구가 뜹니다. 사용하실 공통 비밀번호를 입력하고
Enter 하면 저장됩니다. (화면에 글자가 안 보여도 정상 입력되고 있는 겁니다)

## 7. 배포

```bash
npx wrangler deploy
```

배포가 끝나면 아래와 비슷한 줄이 출력됩니다.

```
https://hyunjang-payment-tracker.<본인계정>.workers.dev
```

이 주소가 앞으로 계속 쓰실 접속 주소입니다. 즐겨찾기 해두시고, 다른 직원분들에게도
이 주소 + 6번에서 정한 비밀번호를 알려주시면 됩니다. PC, 휴대폰 어디서든 이 주소로
들어가서 비밀번호만 입력하면 바로 같은 데이터를 보고 입력할 수 있습니다.

---

## 이후에 다시 수정하고 싶을 때

코드를 수정한 뒤에는 항상 아래 명령 한 줄만 다시 실행하면 즉시 재배포됩니다.

```bash
npx wrangler deploy
```

- 현장 목록 추가/삭제는 코드 수정 없이 화면의 "현장 관리" 버튼으로 하시면 됩니다.
- 비밀번호를 바꾸고 싶으면 `npx wrangler secret put APP_PASSWORD` 를 다시 실행해서
  새 비밀번호를 입력하면 됩니다.

## 화면 구성 안내

- **+ 새 내역 추가**: 현장 선택, 내용, 비용을 입력해서 새로운 줄을 추가합니다.
- **청구 / 입금 체크박스**: 표에서 바로 클릭하면 즉시 저장됩니다. (따로 저장 버튼 없음)
- **입금일**: 표의 날짜 칸을 클릭해서 바로 선택하면 즉시 저장됩니다.
- **수정 / 삭제 버튼**: 현장명·내용·비용을 통째로 고치거나, 잘못 입력한 줄을 지울 때 사용합니다.
- **입금 완료된 줄**은 배경이 연한 초록색으로 바뀌어 완료 내역이라는 게 바로 보입니다.
- 상단 요약 카드에서 전체 건수 / 청구 대기 / 입금 대기 / 입금 완료 합계를 한눈에 볼 수 있습니다.
- 현장/기간(월)별로 필터링해서 볼 수 있습니다.

## 새로 추가된 기능: 시설 업무일지 / 후속 작업 / 작업 내역 및 시설 업무일지 조회

기존 "작업 내역·소독·저수조 청소·히스토리" 화면은 그대로 두고, 상단 탭에 3개 화면이
추가되었습니다.

### 1) 시설 업무일지 탭

매일 현장에서 한 작업을 **현장명 / 작업내역 / 비고** 3가지로 간단히 기록하는 화면입니다.
"+ 새 일지 추가" 버튼으로 그날그날 입력해두면 됩니다. (기존 "작업 내역" 탭의 청구/입금
체크와는 별개의, 순수 작업 기록용 표입니다)

화면 위쪽 "주간 시설 작업일지" / "월간 시설 작업일지" 다운로드 버튼에서 주(week) 또는
월(month)을 고르고 "엑셀 다운로드"를 누르면, 그 기간에 입력해둔 업무일지를 정리한
**엑셀(.xlsx) 파일**이 바로 다운로드됩니다. 회사에서 기존에 쓰시던 "시설 관리
작업일지" 공식 양식(제목/소속·작성자란/주차별 구획/요일별 색상 구분/작성자·대표
서명란 등)을 그대로 재현한 서식으로 만들어지며, 별도 프로그램 설치 없이 엑셀/한셀/
구글 시트로 열어서 그대로 출력하거나 보고용으로 쓰시면 됩니다. 같은 날짜에 업무일지가
여러 건 등록되어 있으면 한 줄에 "1) ... / 2) ..." 형태로 번호를 매겨 함께 담기고,
토요일은 파란색, 일요일은 빨간색으로 눈에 띄게 구분됩니다. (다운로드 시점에 "현장"
필터가 선택되어 있으면 그 현장만 담긴 파일이 만들어집니다)

### 2) 후속 작업 탭

현장에서 확인은 했지만 **앞으로 처리해야 하는 업무**를 등록해두고 놓치지 않게 관리하는
화면입니다. 현장/내용/예정일(선택)/비고를 입력해두면, 목록에서 예정일이 가까운 순으로
보여주고, 처리가 끝나면 "완료" 체크박스만 눌러주면 됩니다. 예정일이 지났는데 아직
완료 체크가 안 된 항목은 줄 배경이 주황빛으로 바뀌어 눈에 띄게 표시됩니다.

### 3) 작업 내역 및 시설 업무일지 조회 탭

**금액을 청구한 "작업 내역" 탭의 기록**과 **시설 업무일지 기록**을 한 화면에서 같이
월별/연도별로 모아보고, 검색도 함께 할 수 있는 화면입니다.

- 기본 화면(월별/연도별 집계표)에는 기간별로 "청구 작업내역 건수" / "시설 업무일지
  건수" / "합계 건수"가 나란히 표시됩니다. 월(또는 연도) 행을 누르면 현장별로 두 건수를
  펼쳐서 볼 수 있고, 현장별 상세 줄을 누르면 그 현장·그 달의 실제 내역(청구 작업내역 +
  업무일지 전부)이 목록으로 바로 나옵니다.
- 위쪽 "전체 / 청구 작업내역만 / 시설 업무일지만" 드롭다운으로 집계·검색 범위를 좁힐 수
  있습니다. 기본값은 "전체"라서 두 종류 모두 함께 보여줍니다.
- 검색창에 현장명이나 작업내용 중 일부 단어를 입력하고 "검색"을 누르면, 기간에
  상관없이 그 단어가 포함된 내역을 청구 작업내역·업무일지 구분 없이 모두 찾아서
  보여줍니다 (검색어는 노란색으로 표시되고, 각 줄에는 "청구 작업내역" / "시설
  업무일지" 배지로 구분이 표시됩니다). "초기화"를 누르면 다시 월별/연도별 집계
  화면으로 돌아갑니다.

### 처음 배포하는 게 아니라, 이미 운영 중인 사이트에 이 기능만 추가하는 경우

이미 `wrangler deploy`로 배포해서 쓰고 계셨다면, 아래 한 줄만 **한 번** 실행해서
데이터베이스에 새 표(업무일지, 후속 작업) 2개만 추가해주시면 됩니다. 기존 현장/작업
내역 데이터는 전혀 건드리지 않으니 안심하고 실행하셔도 됩니다.

```bash
npx wrangler d1 execute bms-money-db --remote --file=./migration_journal_followup.sql
```

("bms-money-db"는 wrangler.toml의 database_name 값입니다. 혹시 다른 이름으로
만드셨다면 wrangler.toml에 적힌 실제 이름으로 바꿔서 실행해주세요)

그다음 평소처럼 코드를 배포하면 새 탭들이 화면에 나타납니다.

```bash
npx wrangler deploy
```

※ 엑셀 다운로드 기능은 `public/vendor/exceljs.min.js` 파일(오픈소스 ExcelJS 라이브러리)을
그대로 사용하며, 별도의 `npm install`이나 추가 설정 없이 배포만 하면 바로 동작합니다.

## 참고 (무료 사용량 관련)

Cloudflare 무료 플랜 기준 Workers는 하루 10만 요청, D1은 하루 500만 행 읽기 /
10만 행 쓰기, 5GB 저장공간까지 무료입니다. 현장 관리비 체크 같은 소규모 내부용
사용량으로는 무료 범위를 넘길 일이 거의 없습니다.

## 문제가 생기면

- `npx wrangler deploy` 실행 시 database_id 관련 오류가 나면 4번 단계에서
  `wrangler.toml`의 `database_id`를 제대로 바꿨는지 확인해주세요.
- 로그인이 계속 안 되면 6번 단계의 비밀번호를 다시 설정(`wrangler secret put APP_PASSWORD`)
  해보세요.
- 그 외 궁금한 점은 캡처와 함께 다시 물어봐 주시면 이어서 도와드리겠습니다.
